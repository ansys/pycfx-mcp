   :classmethod:


   
   Launch a new PyCFX CFX-Pre session and wrap it for MCP use.


   :Parameters:

       **launcher** : :class:`python:str`, default: ``'from_install'``
           PyCFX launcher method to call.

       **ui_mode** : :class:`python:str` | :data:`python:None`, default: :data:`python:None`
           Optional CFX UI mode for the launched process.

       **product_version** : :class:`python:str` | :data:`python:None`, default: :data:`python:None`
           Optional Ansys product version to launch.

       **case_file_name** : :class:`python:str` | :data:`python:None`, default: :data:`python:None`
           CFX case file to open when launching CFX-Pre.

       **start_timeout** : :class:`python:int`, default: 60
           Maximum number of seconds to wait for a launched CFX process.

       **additional_arguments** : :class:`python:str`, default: ``''``
           Additional command-line arguments passed to the CFX launcher.

       **container_dict** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           Container-launch configuration passed to PyCFX.

       **cleanup_on_exit** : :ref:`bool <python:bltin-boolean-values>`, default: :data:`python:True`
           Whether PyCFX should clean up the launched process on exit.



   :Returns:

       'PreSession'
           Session wrapper connected to the requested CFX process.
